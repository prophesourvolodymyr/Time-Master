# F09-B — Knowledge Layer

The AI reads `Knowledge/*.md` on every session start. This is the user's personal fitness framework — their training philosophy, diet rules, recovery protocols. The folder lives inside the data directory and the user creates `.md` files directly (Finder, text editor) or via the AI itself.

Also builds the root-level `AGENTS.md` and `skills/` directory so external AI agents can bootstrap themselves into the workspace.

## What We Build

1. **`Knowledge/` directory** — created at bootstrap, user populates with `.md` files
2. **AI session startup** — scans `Knowledge/` → concatenates all `.md` content → prepended to system prompt
3. **`AGENTS.md`** at root of data directory — tells external AI agents:
   - What this folder is
   - Where to find `schema.json`
   - How to call the `timemaster-tool` CLI
   - What the directory structure means
   - Which folders are safe to read/write
4. **`skills/` directory** — reusable agent skill files:
   - `create-exercise.md` — instructions for creating exercises from user input
   - `build-workout.md` — instructions for assembling workouts from exercises
   - `search-database.md` — instructions for querying the exercise database

## Architecture

```
~/Documents/TimeMaster/
├── AGENTS.md              ← external AI agent bootstrap guide
├── schema.json            ← data contract (generated by F09-A SchemaManager)
├── skills/
│   ├── create-exercise.md
│   ├── build-workout.md
│   └── search-database.md
├── Knowledge/
│   ├── fitness-philosophy.md
│   ├── nutrition-rules.md
│   └── recovery-protocols.md
└── ...
```

## AGENTS.md Content (template)

```markdown
# TimeMaster Data Directory

This is the local file-system database for TimeMaster, a fitness app.

## Structure
- Exercises Database/ — all exercises (folders with manifest.json + guide.md)
- Workouts/ — workout plans referencing exercise IDs
- Media/ — shared media storage (UUID filenames)
- Knowledge/ — AI system prompt material (loaded on session start)
- Workspace/ — free-form AI workspace (app ignores this)
- skills/ — reusable agent skill definitions
- Config/, History/, Music/, Backups/

## How to interact
DO NOT edit files directly. Use the CLI tool:
  timemaster-tool <command> <json-args>
Commands: list-exercises, get-exercise, create-exercise, search-exercises,
          list-workouts, build-workout, list-types, get-stats

## Schema
See schema.json for the full data contract.
```

## States
| State | Behavior |
|---|---|
| First launch | Bootstrap creates `Knowledge/`, `AGENTS.md`, `skills/` with default content |
| Knowledge empty | AI session starts with default system prompt only |
| Knowledge populated | All `.md` files concatenated → prepended to prompt |
| AGENTS.md missing | External AI cannot bootstrap — needs re-bootstrap |
| User edits Knowledge mid-session | Re-loaded on next AI message |

## Files
- `Knowledge/` directory (created at bootstrap)
- `AGENTS.md` (created at bootstrap in data root)
- `skills/` directory with default skill files
- `TimeMasterCore/Sources/AISystemPromptBuilder.swift` — reads Knowledge folder, builds prompt
