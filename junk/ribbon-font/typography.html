02 / TimeMaster page-title spacing

TimeMaster · loading local WOFF2…

This is the real custom TimeMaster WOFF2, not the PNG compositor or a historical rejected font. Use it only for top-of-page and navigation titles. Its advances and sidebearings set the default spacing; built-in kerning makes pair-specific adjustments. Both technical comparison lines below use zero CSS tracking.

A–Z, a–z and ordinary spaces only. Numbers, punctuation, accented letters and other scripts are not included. Unsupported input keeps the last supported preview.

The text, size and tracking are identical. Only the font’s kerning feature changes. A pair without a kerning adjustment may look the same; the unkerned line still uses the naturally tighter spacing stored in the actual font file. Long phrases scroll rather than being squeezed or silently tracked tighter.

Local, offline and font-loading notes

Every preview font comes from a relative local file. No CDN, remote stylesheet or network request is required to render this study. Source links go online only when you follow them. Downloads and licenses are local as well.

A specimen appears only after its actual font file loads. If a face is missing or blocked, its sample stays hidden and its status says unavailable; a system fallback is never presented as the selected face. Keep this page within junk/ribbon-font/ and retain the repository’s folder structure.

Opening the HTML directly works where the browser allows local font URLs. If your browser blocks file:// fonts, serve the Time-Master repository folder with a local HTTP server, then open /junk/ribbon-font/typography.html. HTTP still works fully offline. The canonical TimeMaster files must first be generated; there is no duplicate TTF here.
