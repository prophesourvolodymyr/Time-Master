# P02 — Reverse Engineering Target

For any third-party app, binary, web app, API, or closed-source library: acquire the target, run static analysis (strings, symbols, disassembly), run dynamic analysis (Frida hooks, network capture), isolate the specific feature logic, and extract it into plain-English pseudo-code ready for reimplementation.

## Platforms Covered
iOS, Android, desktop, web, Electron, firmware.

## When to Use
When the feature being built needs to replicate behavior from an existing app or service.
