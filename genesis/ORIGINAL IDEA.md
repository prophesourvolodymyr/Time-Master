# ORIGINAL IDEA — Time-Master

A section-based workout timer iOS app where users create custom workout routines with multiple exercises (sections), each with a name, duration, and custom photo. Run the entire workout with one tap.

## Core Problem
Fitness enthusiasts need seamless, photo-guided workout timers without manually setting timers for each exercise.

## Target Users
Anyone who does structured workouts with timed exercises — gym-goers, home workouters, personal trainers.

## Key Features
- Create/edit/delete custom workouts with multiple timed sections
- Photo attachment per exercise section for visual guidance
- One-tap sequential workout player with countdown timer
- Auto-advance between sections with configurable rest periods
- Audio countdown cues (3-2-1 beeps)
- Workout history logging
- AI-powered exercise naming and coaching
- Video import from computer server for exercise demonstrations
- Analytics dashboard
- Home screen widget for quick workout access
- Background music, motivational quotes, notifications

## Platform
iOS 16+ (SwiftUI), with companion Python server for video import.
